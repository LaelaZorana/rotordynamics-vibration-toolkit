# Data

Everything in this directory is either synthetic or a transcription of
published standard values. Nothing here comes from a real machine or a real
measurement.

## rotors/

Rotor definition files for the loaders in `vibtool.io`.

- `steam_turbine_rotor.yaml`: a three stage industrial steam turbine rotor
  with fluid film bearings, service speed 7500 rpm. Dimensions, masses and
  bearing coefficients are representative values written for this toolkit,
  not taken from any drawing.
- `ev_motor_rotor.json`: a permanent magnet EV traction motor rotor on ball
  bearings, service speed 15000 rpm. Same caveat, and the JSON format
  exercises the second loader path.

Each file carries a station table with section lengths and diameters, disks
with mass and inertias, bearings with stiffness and damping at named
stations, and unbalance cases. The G2.5 cases follow ISO 21940-11, which
sets the permissible residual specific unbalance through e_per times omega
equal to the grade value, so G2.5 at 7500 rpm gives e_per of 3.18
micrometres and U_per of 1.50e-3 kg m for a 470 kg rotor.

## runup_turbine_synthetic.csv

A synthetic run up measurement, generated by
`examples/generate_runup_data.py` from the toolkit's own Jeffcott model of
the turbine rotor with a fixed random seed. Columns are time, speed in rpm,
and the 1x amplitude in micrometres and phase lag in degrees at two shaft
probes 90 degrees apart. A slow roll runout vector and gaussian noise are
added at each probe. The generating model has its first critical at 4200
rpm with a damping ratio of 0.045, which is what the identification example
should recover. This file is synthetic and must never be presented as a
real machine record.

## standards/

- `iso21940-11_balance_grades.csv`: balance quality grades G0.4 to G4000
  with the e_per times omega value in mm/s and typical machinery, as
  tabulated in ISO 21940-11:2016, Balance quality requirements for rotors
  in a constant rigid state, Table 1 (formerly ISO 1940-1).
- `iso10816-3_zone_limits.csv`: broadband vibration velocity zone
  boundaries in mm/s rms for group 1 and group 2 machines on rigid and
  flexible supports, as tabulated in ISO 10816-3:2009, Evaluation of
  machine vibration by measurements on non rotating parts, Annex A (now
  carried forward into ISO 20816-3). Zone A is new machine condition, B is
  unrestricted long term operation, C is restricted operation and D is
  damage risk.

The CSV values are transcriptions for convenience. Anyone making an
acceptance decision should read the standard itself.
